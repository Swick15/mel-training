# Mel's Training

A phone-friendly guide for Mel's 2-week gym block: guided EMOM, AMRAP, interval and for-time timers, plus a week 1 vs week 2 score tracker.

Live at https://swick15.github.io/mel-training/

- `index.html` is the page source.
- `sh build.sh` wraps it into `docs/index.html`, which GitHub Pages serves along with the icons and manifest in `docs/`.
- Scores are saved in the browser on the phone that logs them.
